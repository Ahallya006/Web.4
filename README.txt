AHALLYA J.S. — STATIC PORTFOLIO
================================

Files
- index.html : page content and sections
- style.css  : responsive styling and palette inspired by the provided colourful strand reference
- script.js  : mobile navigation and dynamic footer year

How to open
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. No build tools, frameworks, or package installation are required.

Edit your details
- Contact details are in index.html (search for the email or phone number).
- Update the summary, project descriptions, skills, education, and experience directly in index.html.
- Palette variables are at the top of style.css under :root.
- Google Fonts are loaded from Google Fonts when internet is available; fallback fonts are included.

Notes
- This is a static portfolio using only HTML, CSS, and vanilla JavaScript.
- The project descriptions are based on the uploaded resume. Add verified technical details, live demos, or GitHub links when available.
